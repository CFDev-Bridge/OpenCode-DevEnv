Proyectos

Proyecto destacado

OpenCode-DevEnv

Entorno de desarrollo reproducible para OpenCode, aislado mediante Docker y gestionado con Git.

Dockerfile · 2026
  • BaseUbuntu 24.04 con Node.js 22 LTS, Python 3 y Git
  • SeguridadUsuario sin privilegios, cap_drop: ALL y no-new-privileges
  • PersistenciaWorkspace por bind mount: los proyectos sobreviven al contenedor
  • VersionadoSolo se versiona el entorno; los proyectos de trabajo quedan fuera de Git
# levantar el entorno
$ docker compose up -d
$ docker exec -it opencode bash
$ opencode

# reconstruir tras cambiar el Dockerfile
$ docker compose up -d --build
